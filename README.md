
# SM/SL Calculator

A mobile-friendly calculator for daily store performance and service-level reporting.

## Features

- Target Sales calculation
- Actual Sales entry using multiple amounts
- Guest Count and Average Count
- Crew Labor in Peso and Percentage
- Crew Labor Hours
- GCPCH calculation
- Target Raw Waste and Complete Waste
- Actual Raw Waste and Complete Waste entry
- R2P, OEPE, and PAT service timings
- Target vs Actual Variance Report
- Daily target records saved by date

## Installation

1. Upload all project files to a web host that supports HTTPS.
2. Open the calculator using your browser.
3. Add the app to your phone's home screen.
4. Open the calculator from the installed app icon.

## Daily Usage

1. Select TARGET.
2. Enter the projected figures.
3. Target results are saved by date in your browser.
4. Select ACTUAL.
5. Enter actual sales, GC, crew information, waste, and service timings.
6. Select SHOW VARIANCE to compare Target and Actual.

## Data Storage

Target records are stored in the browser's Local Storage.

Records are saved on the device and browser being used.

Clearing browser data may erase saved records.

The records are not automatically synchronized between devices.
